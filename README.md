# hono-cloudflare-workers-samples

Sample code for the book 「**Hono + Cloudflare Workers 実践入門 — 無料枠で動くフルスタックWebアプリを作る**」 by 牧野 誠 (Amazon Kindle, 価格 ¥980)

## 各章のサンプル

- `ch01-hono-basics/` — Ch1: Hono の基礎
- `ch02-workers-overview/` — Ch2: Cloudflare Workers の全体像
- `ch03-typescript-api/` — Ch3: TypeScript API パターン
- `ch04-d1-drizzle/` — Ch4: D1 + Drizzle ORM
- `ch05-r2-kv/` — Ch5: R2 + KV
- `ch06-auth-security/` — Ch6: 認証・セキュリティ
- `ch07-blog-api/` — Ch7: ブログ API プロジェクト
- `ch08-saas-mvp/` — Ch8: SaaS MVP プロジェクト
- `ch09-workers-ai/` — Ch9: Workers AI
- `ch10-testing-cicd/` — Ch10: テスト・CI/CD・運用

## 動作要件

- Node.js 22+
- npm or pnpm
- Cloudflare アカウント (無料プランで動作)
- Wrangler CLI (`npm install -g wrangler`)
